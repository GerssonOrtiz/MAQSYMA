# Categorías y filtros identificados

## Navegación
- Productos para soldadura y corte
- Máquinas de soldar
  - Proceso GMAW (Alambre Sólido)
  - Proceso FCAW (Alambre Tubular)
  - Proceso SMAW (Electrodo Revestido)
  - Proceso GTAW-TIG (Electrodo de Tungsteno)
  - Multiproceso
- Soldadora láser
- Motosoldadoras (incluye Multiproceso)
- Alimentadores
- Complementos: Accesorios, Antorchas, EPP, Flujómetros y Anti-Spatter
- Alquiler
- Nosotros
- Contacto

## Filtros visibles en Máquinas de Soldar
- Precio mínimo y máximo
- Corriente máxima: 120A, 130A, 160A, 200A, 210A, 230A, 240A, 250A, 300A, 350A, 400A, 410A, 420A, 500A, 600A y 820A
- Proceso: FCAW, GMAW, GTAW, Multiproceso, SMAW
- Tipo: Industrial, Portátil, Trabajo pesado
- Tensión de entrada: Monofásica, Trifásica

Estos filtros no prueban qué atributos corresponden a cada producto. Asignarlos solo después de verificar la ficha individual.
