# MAQSYMA — paquete para implementación

Paquete de referencia extraído del sitio público https://maqsyma.com/ para apoyar la actualización de https://maqsyma-app.vercel.app/#taller.

**Fecha de consulta:** 12/11/2026.

Incluye catálogo, categorías, información comercial, guía técnica para el agente y un manifiesto de imágenes oficiales.

**Limitación importante:** se verificaron las URL de las fotografías, pero el entorno no permitió descargar los archivos binarios del servidor externo. Por ello el ZIP incluye enlaces directos a las fotos, no archivos de imagen locales. Las fotos deben descargarse desde `docs/FOTOGRAFIAS.md` antes de incorporarlas al repositorio.
